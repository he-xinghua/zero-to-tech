# 计划：改进 3 个小游戏

## 概述

基于搜索到的公开数据，对现有的 3 个游戏进行针对性改进，保持文件数量不变（5 个）。

---

## 改进 1：反应速度测试 — 增加结果评估

### 问题
当前仅显示毫秒数值，用户无法判断自己的水平。

### 数据来源（来自 humanbenchmark.me 等多来源综合）
| 评级 | 反应时间 | 对应人群 |
|------|----------|----------|
| 🏆 卓越 | < 150ms | 前 1% |
| 🥇 精英 | 150-180ms | 职业电竞选手 |
| 🥈 优秀 | 180-210ms | 前 15% |
| 🥉 良好 | 210-250ms | 前 35% |
| 平均 | 250-300ms | 正常成人 |
| 偏慢 | 300-350ms | 低于平均 |
| 待改善 | > 350ms | 后 20% |

### 改动
- 每次测试后，在反应时间下方显示评级标签（如 `🏆 卓越` / `🥇 精英`）
- 完成 5 次测试后，显示平均反应时间 + 综合评级
- 保留最好成绩存储
- 在帮助提示中增加简要的参考等级显示

## 改进 2：数字广度 — 修复连续数字无法分辨问题

### 问题
当序列中出现连续相同数字（如 `3, 3`），显示内容没有任何变化，用户误以为只出现了一个数字。

### 原因
`digitDisplay.textContent = 3` → 再设置为 `3`，DOM 不变，视觉上无感知。

### 方案
在相邻数字之间插入 **200ms 空白帧**，使每次数字变化都有视觉过渡：

```
显示流程：
  数字1 (800ms) → 空白 (200ms) → 数字2 (800ms) → 空白 (200ms) → ...
```

### 改动
- 将 `setInterval` 改为 `setTimeout` 递归调用，实现精细的时序控制
- 每个数字独占 800ms + 200ms 间隔 = 1000ms/位，总时长不变

## 改进 3：划消任务 — 电竞级难度

### 问题
当前任务（6×5 网格找字母 A，干扰项 B-H）对电竞玩家过于简单。

### 改进方案
从电竞训练平台参考设计，采用 **数字识别 + 高混淆干扰** 的视觉搜索任务：

| 要素 | 当前 | 改进后 |
|------|------|--------|
| 网格 | 6×5 (30 格) | 8×5 (40 格) |
| 目标 | 字母 A | 数字 `6` |
| 干扰项 | B-H (容易区分) | `8`, `9`, `0`, `5` (视觉混淆) |
| 时限 | 30 秒 | 15 秒 |
| 目标数 | 10 个 A | 12 个 `6` |
| 反馈 | 点错恢复原样 | 点错标记 500ms 后复原 |
| 评价 | 无 | 根据完成数 + 准确率评级 |

### 干扰物相似性设计
- `6` 和 `8` / `9` / `0` 视觉形态接近
- 需要集中注意力才能区分，类似 esports 训练中的视觉搜索

### 结果评级（基于准确率 + 完成度）
| 评级 | 条件 |
|------|------|
| S | 12/12 + 无错误 |
| A | 10-11/12 + 错误 ≤2 |
| B | 8-9/12 |
| C | ≤7/12 |
